# Skill Bundler 0.2.0

_Released 2026-09-24_

This release adds a survey mode: point the tool at a folder of skills and get one shareable document describing all of them.

## Highlights

- **Collection survey**: `skill-bundler index` turns a whole collection of skills into a single Markdown document, opening with a Skill Index table and followed by each skill's instructions in full.
- **Nested collections**: pass `-r` to include skills tucked into subfolders, not just the top level.
