**Why it matters**: The helper `is_safe_relative_path` checks `if relative_path.is_absolute(): return False` before resolving paths. Because `dest` is absolute, the test exits early on the absolute path check and never exercises the `dest == target_resolved` root collision rejection logic on line 141 of `unpacker.py`.
